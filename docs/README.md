# Guide de lecture

**Révision reçue le 19 octobre :** commencer par la [revue des corrections et des points ouverts](11-revue-corrections-2026-10-19.md).

Ce guide sépare les valeurs présentes dans les fichiers, les calculs et les validations encore nécessaires. **Lire l'[audit](07-audit-technique.md) avant de commander ou d'alimenter une carte.**

## Parcours de découverte

1. [Fonctionnement](01-fonctionnement.md) : continu, transformateur, résonance, redressement et sinusoïde.
2. [Connectique](02-connectique.md) : J1/J2, J4, J5, J7 et domaines de masse.
3. [DC-DC](03-reglage-dcdc.md) : calcul LC, identification du module et mesure de fréquence.
4. [Onduleur EGS005Q](04-reglage-onduleur.md) : réglages de sortie et commandes du module.

## Parcours de construction

1. Lever les anomalies de l'[audit](07-audit-technique.md).
2. Compléter les achats et le dossier [fabrication](05-fabrication.md).
3. Préparer le banc et remplir la [fiche de mise en service](06-mise-en-service.md).
4. Publier les valeurs mesurées et la révision exacte utilisée selon [CONTRIBUTING](../CONTRIBUTING.md).

Les [sources](08-sources.md) indiquent les versions des notices consultées. Les [rapports bruts](reports/README.md) permettent de vérifier les constats. Une fréquence calculée n'est pas un réglage qualifié ; un voyant vert n'est pas une preuve de sécurité électrique.

## Batterie et ressources cirBATT

Le [guide batteries de seconde vie](09-batteries-seconde-vie.md) relie l'onduleur au pack et au BMS. Pour découvrir la marque, consulter [cirBATT](https://cirbatt.com/) ; pour approfondir les notions, son [blog batteries lithium et réemploi](https://cirbatt.com/blog).
